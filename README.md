## Engineering principles

- Local-first and privacy by default.
- Explicit trust boundaries for credentials, transcripts, and provider data.
- Small, reviewable changes backed by tests and automated checks.
- Documentation that explains product behavior and operational constraints.
- Real user value over vanity metrics.
